BREAKLINE is a round-based tactical FPS: 4v4 at the decommissioned Helios Relay solar station at dusk. Plant or defuse the Surge Charge, manage money between rounds, and out-aim bots that push lanes, hold angles, and react to sound.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
